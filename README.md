# SokoSignal synthetic demo fixtures

This repository contains project-created, invented market-comparison records
for software and MCP retrieval tests. Every quote is synthetic. Market A and
Market B are fictional; prices, costs, grades, dates and capacity are test inputs.
Negative variants intentionally exercise invalid or incomplete inputs.

No KAMIS observations, personal records, live prices or real buyer commitments
are included. Do not use these records for farming, trading or financial decisions.
The fixture is distributed unchanged, with its original synthetic labels.
